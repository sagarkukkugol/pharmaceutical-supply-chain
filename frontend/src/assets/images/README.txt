HOMEPAGE PHOTOS — replace a file to replace that image.

Put your photos in this folder using EXACTLY these names (.jpg, .jpeg, .png
or .webp all work):

  hero-pharmaceutical   Hero (right side of the first screen)
  manufacturer          How It Works - Manufacturer
  transporter           How It Works - Transporter
  distributor           How It Works - Distributor
  pharmacy              How It Works - Pharmacy
  consumer              How It Works - Consumer
  partner               Partner Login section (optional)

No code changes are needed. Images are cropped to fit (object-fit: cover),
so any landscape photo works; about 1600x900 and under 400 KB is ideal.
Until a file exists, that spot shows a simple illustrated placeholder.
Only use photos you own or are licensed to use.
